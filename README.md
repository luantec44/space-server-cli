# SSHPLUS SPACE PRO — distribuição pública

Distribuição compilada da base estável v1.9.12 com a interface móvel azul de duas colunas (opções 01–27), desenvolvedor `@luantech`.

Instalação:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/luantec44/space-server-cli/main/install.sh)"
```

Após finalizar:

```bash
space
```

O repositório de distribuição contém apenas o bootstrap público e os executáveis Linux amd64/arm64. O pacote funcional é carregado internamente pelos executáveis de instalação.
